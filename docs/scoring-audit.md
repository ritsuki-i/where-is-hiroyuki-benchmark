# 判定・実験条件の確認

## 最新レースでのJevの判定

実行 `759be9da6e3c4022a70d11fec144ae39` では、Jevは5ステージとも「予測枠の中心が正解顔枠内」という基準で不正解でした。ただし、[ステージ1の画像](runs/759be9da6e3c4022a70d11fec144ae39/stage1.md)では対象人物を囲んでおり、予測枠は目視で作成した正解顔枠の面積の **90.8%** を含んでいます。予測枠が人物全体に近く、その中心が顔の外にあるため不正解です。「対象を見つけていない」と解釈するのは適切ではありません。

同じ実行のJevの正解顔枠に対する被覆率は、ステージ1から順に **90.8%、44.0%、0%、0%、0%** でした。被覆率は正解顔枠のうち予測枠と重なった面積の割合です。広い枠でも高くなり得るため、それだけで顔枠の精度を示す値ではありません。正解枠自体も目視による概算です。

中心基準はステージ1を取りこぼす一方、広い枠でも中心だけが顔に入っていれば正解とすることがあります。過去の動画とREADMEの整合性を保つため、保存済みレースの正解数は書き換えていません。人物を見つけたかと顔を精密に囲めたかは別の指標として扱う必要があります。

## 以前の実験との違い

- 以前のJevの実装は顔が一致する**人物全体**の枠を要求し、人物の正解枠との重なりで採点していました。現在は**顔のみ**の枠を要求し、予測枠の中心で採点しています。指示も採点対象も変わったため、数値をそのまま比較できません。
- 以前のClefの **2/5** は、YuNetで検出した顔の候補一覧からClefが選択した [YuNet + Clefの補助実験](additional-experiments.md)です。現在のClef単体は候補検出器を使わず、画像から4座標を選択しています。最新レースの **0/5** は別の方式の結果です。
- 現在のClef方式では左右上下を個別に選択するため、上と下が逆になるなど有効な矩形にならない場合があります。最新レースでもこのような応答があり、そのまま枠なし・不正解として記録しました。これをClefのすべての利用方法における性能とは解釈できません。

各結果はそれぞれ1回の試行であり、モデルの応答や所要時間は変動します。レースの記録と表示は当時の条件のまま保持し、新たな判定基準を採用する場合は基準と結果を明示して別に記録します。
